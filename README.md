# ELEV8 SPORTSWEAR


## 📌 Descripción

ELEV8 SPORTSWEAR es una tienda de ropa deportiva de alto rendimiento desarrollada con **Java EE** (Servlets y JSP) y **PostgreSQL** como base de datos.

---

## 🛠️ Tecnologías utilizadas

| Tecnología | Versión |
|------------|---------|
| Java | 17 |
| Jakarta Servlet | 6.0.0 |
| Jakarta JSP | 3.1.1 |
| JSTL | 3.0.0 |
| PostgreSQL | 15+ |
| BCrypt | 0.4 |
| Maven | 3.9+ |
| Apache Tomcat | 10.1+ |
