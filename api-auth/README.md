# Elev8 Auth API - Servicio de Autenticación

## 📌 Descripción

Servicio de autenticación para Elev8 Sportswear desarrollado con Node.js, Express y MongoDB.

## 🚀 Instalación y ejecución

```bash
# 1. Instalar dependencias
npm install

# 2. Configurar variables de entorno (.env)
# 3. Iniciar MongoDB
# 4. Ejecutar el servidor
npm run dev
